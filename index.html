🚌 Campus Transport Pass System

Mini Project by Team GenZ Trio

About This Project

Problem: Students and staff have to request and renew bus passes manually on paper.

Our Solution: A simple online system where a student fills a form, admin approves it, and a pass is generated with an expiry date and a pass number.

Steps in this project:

  1. Student creates a profile
  2. Student selects a bus route
  3. Student requests a pass
  4. Admin approves or rejects the request
  5. If approved, a pass number and expiry date is generated
  6. Anyone can validate a pass number on the Validate page
